# ARSM 网页助手

该目录是可由 Chrome 或 Edge 以“加载已解压的扩展程序”方式安装的 Manifest V3 扩展。

## 安装

1. 在 ARSM Suite 的“设置 → 浏览器扩展”中启用本机连接；
2. 点击“打开扩展目录”；
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`；
4. 开启开发者模式，选择“加载已解压的扩展程序”；
5. 选择本目录；
6. 在扩展设置页粘贴 ARSM 显示的连接令牌并检查连接。

浏览器安全策略不允许 ARSM 静默安装或卸载扩展。卸载时请在浏览器扩展管理页点击“移除”，随后可在 ARSM 设置中停用本机连接。

## 安全边界

- 只访问 `https://asmr.one/*` 与 `https://www.asmr.one/*`；
- 只连接 `http://127.0.0.1:17641`；
- 令牌只保存在扩展的本地存储；
- 网页内容无法读取令牌；
- 扩展不下载文件、不读取媒体目录、不接收绝对路径；
- 所有下载和重复检查均由 ARSM Suite 完成。
